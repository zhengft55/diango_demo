🧩 一、django-admin startproject <项目名>

作用：创建一个新的 Django 项目骨架

📦 它会生成整个 Django 项目的“外壳结构”，包含：

项目配置（settings、urls、wsgi/asgi）

管理命令入口（manage.py）

初始化 Python 包结构（__init__.py）

✅ 语法
django-admin startproject myproject


或等价于：

python -m django startproject myproject

✅ 生成目录结构示例
myproject/
├── manage.py              # 项目管理入口（runserver、migrate 等命令）
└── myproject/             # 真正的项目包
    ├── __init__.py
    ├── asgi.py
    ├── settings.py        # 全局配置（数据库、时区、INSTALLED_APPS 等）
    ├── urls.py            # 路由定义入口
    └── wsgi.py


🧩 二、python manage.py startapp <应用名>

作用：在项目内部创建一个新的 Django 应用模块（App）

📦 每个 app 通常负责一类功能，比如：

用户管理（users）

订单管理（orders）

支付模块（payments）

✅ 语法
python manage.py startapp orders


注意这里必须用 python manage.py（而不是 django-admin），
因为 Django 需要知道这是在哪个项目环境下创建的 app。

✅ 生成目录结构示例
orders/
├── __init__.py
├── admin.py          # 后台管理定义
├── apps.py           # App 配置类
├── migrations/       # 数据库迁移文件目录
│   └── __init__.py
├── models.py         # 数据模型（定义数据库表）
├── tests.py          # 单元测试
└── views.py          # 视图函数或类视图（业务逻辑）
